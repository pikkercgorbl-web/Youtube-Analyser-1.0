# Fix 2C — термины интерфейса

| Было | Стало | Смысл |
|------|-------|--------|
| Базовая линия канала (сырые Status / Comparable videos) | Сравнение с недавними роликами канала | VPH vs сопоставимые ролики канала по снимкам окна Attention |
| «Недостаточно сопоставимой истории канала» (как вердикт) | Сравнение недоступно — ограничение данных | Не оценка качества канала |
| Название + кнопка YouTube на карточке Winner | Заголовок + одна кнопка «Смотреть на YouTube» | Один очевидный переход |
| Связанные темы (без video_id) | Запросы, по которым нашли это видео (`video_id`) | Запрос = источник Discovery |
| Связанные запросы (family) | Запросы подборки (источник поиска) | Объясняют группировку, не тему каждого ролика |
| Все уникальные видео семейства | Ролики подборки для ручного сравнения | Ручной обзор состава |
| Исходные паттерны | Пересечение групп по запросам и видео (для search collection) | Keyword/video overlap, не доказанное сходство |
| (нет) | Статус измерения просмотров | from_winner_snapshot / missing_snapshot / zero_* / unknown_* |
| Похожие находки (ожидание пользователя) | Пересечение групп / подборки поиска | Не подтверждённая похожесть формата |

## Проблемы данных (UI не исправляет)

- Channel-relative v1 использует только снимки в окне lookback Attention — полная история канала недоступна.
- У участников подборки без Winner-снимка часто нет `VideoSnapshot` → просмотры/VPH пустые.
- Текст запроса для старых сохранений без `keyword_ids` в frozen evidence не восстановить.
- `pattern_candidate_build` в summary.notes может быть null до следующего Attention refresh.
