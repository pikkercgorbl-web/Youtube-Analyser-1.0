# Как запустить сайт

## Что было не так

1. **Бэкенд** — пытался подключиться к PostgreSQL, которого нет на компьютере.  
   **Исправлено:** по умолчанию используется SQLite (файл `data/youtube_analytics.db`).

2. **Фронтенд** — команда `npm` не найдена, потому что **Node.js не установлен**.

---

## Шаг 0: Установите Node.js (один раз)

1. Откройте https://nodejs.org/
2. Скачайте **LTS** (рекомендуемая версия)
3. При установке включите **«Add to PATH»**
4. **Закройте и снова откройте** терминал / Cursor

Проверка:
```powershell
node -v
npm -v
```

---

## Шаг 1: Запуск бэкенда

В терминале из **корня проекта** (`Сайт анализ ниш`):

```powershell
.\scripts\start-backend.ps1
```

Или вручную:
```powershell
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Откройте: http://127.0.0.1:8000/docs — должна открыться документация API.

---

## Шаг 2: Запуск фронтенда

**Второй терминал**, из корня проекта:

```powershell
.\scripts\start-frontend.ps1
```

Или вручную:
```powershell
cd frontend
npm install
copy .env.local.example .env.local
npm run dev
```

Откройте: http://localhost:3000

---

## YouTube API

В файле `.env` в корне проекта замените ключи:

```
YOUTUBE_API_KEYS=ваш_ключ_из_google_cloud
```

Без ключей бэкенд запустится, но поиск и анализ через YouTube не будут работать.

---

## Частые ошибки

| Ошибка | Решение |
|--------|---------|
| `npm не распознано` | Установите Node.js, перезапустите терминал |
| `cd frontend` дважды | Вы уже в папке `frontend`, не делайте `cd frontend` снова |
| `Connection refused port 5432` | Используйте `.env` с SQLite (см. `.env.example`) |
| Сайт пустой / ошибки API | Сначала запустите бэкенд, потом фронтенд |
